== Cross-cutting Concepts

=== Development Concepts

Vividly is built with React Native for cross-platform mobile development, targeting both iOS and Android from a single codebase. The architecture follows clean architecture principles with a clear separation of three layers:

* *UI layer* — React Native components, screens, and navigation
* *Business logic layer* — use cases, state management, and domain rules
* *Data layer* — repositories, API clients, and local storage

This separation ensures the codebase remains maintainable as the team grows, and makes unit testing each layer independently straightforward.

=== Architecture and Design Patterns

The following patterns are applied consistently across the system:

* *MVVM (Model-View-ViewModel)* — used in the UI layer to separate presentation logic from UI components, keeping screens lean and testable.
* *Repository pattern* — used in the data layer to abstract data sources (REST API, local cache) behind a single interface, so business logic never depends directly on a specific data source.
* *REST APIs* — all client-server communication follows REST conventions over HTTPS, with JSON as the data format.

=== Safety and Security Concepts

Security measures are applied uniformly across all parts of the system:

* *HTTPS* — all API calls are encrypted in transit; plain HTTP is not permitted.
* *JWT (JSON Web Tokens)* — authentication is stateless and token-based. Tokens are signed server-side and validated on every protected request.
* *Password hashing* — user passwords are hashed using bcrypt before storage and are never stored or logged in plain text.
* *GDPR compliance* — personal data, images, and payment information are handled according to GDPR requirements (TC_3), including data minimization and secure storage.
