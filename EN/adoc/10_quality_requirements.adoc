== Quality Requirements

=== Quality Scenarios

[options="header",cols="1,2,3"]
|===
|Quality Goal|Scenario|Acceptance Criterion

|Performance Efficiency
|A user uploads a photo on a mobile connection.
|The photo appears in the feed within 3 seconds.

|Usability
|A new user opens the app for the first time with no instructions.
|The user can register, upload a photo, and apply a filter within 5 minutes.

|Security
|A user's account data and payment information are stored in the system.
|User passwords and payment data are encrypted; no sensitive data appears in logs or error messages.

|===
