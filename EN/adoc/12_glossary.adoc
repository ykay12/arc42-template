== Glossary
 
[cols="1,3", options="header"]
|===
| Term | Definition
 
| ADR
| Architecture Decision Record — a short document capturing a significant architectural decision, its context, and its consequences.
 
| Amazon CloudFront
| AWS's global Content Delivery Network used as the CDN / Edge layer. Serves static assets and processed images to users at the nearest edge PoP, reducing latency and origin load.
 
| Amazon EKS
| Elastic Kubernetes Service — AWS's managed Kubernetes offering used to host and orchestrate the four SOA services in the Application Cluster.
 
| Amazon ElastiCache
| AWS's managed in-memory caching service running Redis. Used for session storage, feed caching, and rate-limit counters.
 
| Amazon OpenSearch
| AWS's managed search and analytics service (based on Elasticsearch) used to index image tags and power full-text search across the platform.
 
| Amazon RDS
| Relational Database Service — AWS's managed PostgreSQL offering. Deployed in a Multi-AZ configuration with a primary write node and a read replica for the shared application database.
 
| Amazon S3
| Simple Storage Service — AWS's object storage service used to store original and processed image files as well as static assets. Server-side encryption (SSE-S3) is enabled; a lifecycle policy archives originals to Glacier after 365 days.
 
| Amazon SQS
| Simple Queue Service — AWS's managed message queue service used as the shared service bus. Carries events such as `image.uploaded`, `interaction.created`, and `challenge.submitted` between SOA services.
 
| Apple App Store
| Apple's distribution platform for iOS applications. The iOS App is submitted, reviewed, and distributed to end users through the App Store.
 
| Apple IAP
| Apple In-App Purchase — Apple's payment framework for handling subscription purchases within the iOS App, required for App Store compliance.
 
| APNs
| Apple Push Notification service — Apple's platform for delivering push notifications to iOS devices.
 
| BRD
| Business Requirements Document — the source document for this product's functional and business requirements.
 
| Capability Token
| A JWT claim array (`caps`) that encodes which premium features a user is entitled to access, based on their current subscription plan.
 
| CDN
| Content Delivery Network — a geographically distributed network of servers (CloudFront) that serves static assets and images close to the user.
 
| CI/CD
| Continuous Integration / Continuous Delivery — a software delivery practice in which code changes are automatically built, tested, and deployed. In this project, every service has its own CI/CD pipeline; pull requests trigger automated builds and test suites, and passing builds are automatically deployed to staging via Kubernetes rolling updates.
 
| Cross-cutting Concept
| A concern that applies across multiple services or layers of the architecture rather than being owned by a single component — for example, authentication, logging, error handling, and GDPR compliance. Arc42 Section 8 documents all cross-cutting concepts for this product.
 
| DLQ
| Dead-Letter Queue — a secondary SQS queue that receives messages that could not be processed after the maximum number of retries.
 
| EditingService
| The SOA service responsible for in-app image editing, filter management, and the Pixlr integration.
 
| EntityManager
| The shared ORM and domain model abstraction used by all SOA services to access the PostgreSQL database.
 
| Facebook API
| Meta's Graph API used by ContentService to allow users to share images directly to their Facebook profiles from within the app.
 
| FCM
| Firebase Cloud Messaging — Google's cross-platform push notification service used by NotificationService to deliver push notifications to Android devices.
 
| Freemium
| A business model offering a free tier with limited features and a paid subscription for advanced features.
 
| Google IAP
| Google In-App Purchase — Google's payment framework for handling subscription purchases within the Android App, required for Play Store compliance.
 
| Google Play Store
| Google's distribution platform for Android applications. The Android App is submitted, reviewed, and distributed to end users through the Play Store.
 
| GDPR
| General Data Protection Regulation — EU regulation (2016/679) governing the collection, processing, and storage of personal data of EU residents. The app must comply with GDPR requirements including lawful basis for data processing, right of access (Article 15), right to erasure (Article 17), and data portability (Article 20). The UserDeletionSaga implements the erasure workflow.
 
| GraphQL Federation
| An approach (using Apollo Federation) to compose a unified GraphQL schema from multiple services.
 
| HEIC
| High Efficiency Image Container — the default image format on modern iOS devices.
 
| Hashing
| A one-way cryptographic transformation that converts input data (such as a password or user ID) into a fixed-length digest. The app uses bcrypt for password hashing (cost factor 12) and SHA-256 for non-sensitive identifiers such as user IDs in log entries, ensuring personal data is never logged in plain text.
 
| HTTPS
| Hypertext Transfer Protocol Secure — HTTP layered over TLS (Transport Layer Security). All communication between clients, the API Gateway, external services, and the CDN uses HTTPS with TLS 1.3 as a mandatory baseline, required by both Apple App Store and Google Play Store policies.
 
| Instagram API
| Meta's Instagram Graph API used by ContentService to allow users to share images directly to their Instagram profiles from within the app.
 
| Jaeger
| An open-source distributed tracing platform used in the Monitoring zone to track requests as they flow across SOA services, helping diagnose latency and errors.
 
| JWT
| JSON Web Token — a compact, URL-safe token format used to represent claims (identity, capabilities) between parties.
 
| Kong
| An open-source API gateway used as the single entry point for all mobile API traffic. Handles JWT validation, rate limiting, request routing, and TLS termination.
 
| mTLS
| Mutual TLS — a variant of TLS where both client and server authenticate each other using certificates; used for inter-service communication.
 
| PagerDuty
| An incident management and alerting platform that receives alerts from Prometheus and the ELK stack and notifies on-call engineers of critical issues.
 
| Pixlr
| A cloud-based photo editing SaaS platform. Integrated into EditingService via an OAuth 2.0 redirect flow, allowing users to access advanced editing tools without leaving the app.
 
| Prometheus
| An open-source metrics collection and alerting toolkit used in the Monitoring zone. Scrapes metrics from all SOA services; paired with Grafana for dashboards.
 
| REST API
| Representational State Transfer Application Programming Interface — the primary synchronous communication style used between mobile clients and the API Gateway. REST endpoints follow standard HTTP verbs (GET, POST, PUT, DELETE) and return JSON. Used for all CRUD operations; GraphQL is used alongside REST for complex feed queries.
 
| RESP
| REdis Serialization Protocol — the binary protocol used by Redis clients.
 
| SendGrid / SES
| Transactional email delivery services. SendGrid (primary) and Amazon SES (fallback) are used by NotificationService to send registration confirmations, password resets, and subscription receipts.
 
| SOA
| Service-Oriented Architecture — an architectural style in which functionality is grouped into coarse-grained, interoperable services that communicate via well-defined contracts and a shared service bus.
 
| SSE-S3
| Server-Side Encryption with Amazon S3-Managed Keys — encryption at rest applied to all objects in S3.
 
| Stripe
| A payment processing platform used by UserService to handle subscription billing. Stripe webhooks notify the application of successful payments, failures, and cancellations.
 
| UserDeletionSaga
| A workflow orchestrated by UserService that processes GDPR right-to-erasure requests across all services and data stores.
 
| WebP
| A modern image format by Google offering superior compression; used for all derivative image sizes served via CDN.
|===
